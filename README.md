# AT-99-Scorpion
AT-99 Scorpion, designed in CATIA V5, is a fictional VTOL tiltrotor light attack aircraft used by the RDA (Resources Development Administration) in the movie Avatar. It's a Mosquito-class VTOL gunship designed for close air support in hostile environments. It features a sealed, pressurized cockpit &amp; is armed with various missiles and machine guns.
